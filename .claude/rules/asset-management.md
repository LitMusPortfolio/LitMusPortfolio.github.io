# アセット管理

## 配置場所

全ての画像・動画アセットは `public/` ディレクトリ以下に配置する。

## 番号プレフィックス

ディレクトリは番号プレフィックスで整理:

```
public/
├── 001_top/       # トップページ用
├── 101_Lit/       # 離途関連
├── 102_xxx/       # その他キャラクター
└── ...
```

## 最適化フォーマット

| 種類 | 推奨フォーマット | 備考 |
|------|-----------------|------|
| 画像 | WebP | 透過が必要な場合も WebP を優先 |
| 動画 | WebM | 背景動画などに使用 |

## 遅延読み込み

アセットの読み込みには専用コンポーネントを使用:

- `LazyImage` - 画像の遅延読み込み
- `LazyVideo` - 動画の遅延読み込み

これらは IntersectionObserver を使用してビューポート内に入ったときに読み込みを開始する。
